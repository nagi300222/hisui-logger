# 陽彗ログ 試作品 v0.5

## v0.5の主な変更
- 簡易スコアタブ追加
- 試合後メモ保存後に簡易スコアへ移動
- 簡易スコアの根拠を羅列
- 技候補ボタンは選択中の技枠へ反映
- 特性欄を基本プルダウンに統合。自由入力は必要時のみ表示
- AS/CS/HA/HC/HB/HD/HSの標準配分ボタン
- 能力ポイント合計66制限
- メガはボタンでON/OFF
- 状態異常・場状態は折りたたみ
- 上位50スターターDBを搭載
- イダイトウなどの候補データを構築登録側にも反映
- ブロック023 crazyluvdisc戦のサンプルログ入力ボタン追加

## 注意
上位50の順位は外部攻略サイトの使用率ランキングを参考にしたスターターです。
技・特性・型データは入力補助であり、完全な合法性保証ではありません。
